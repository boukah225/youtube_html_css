# YouTube HTML/CSS

Projet de création d'une interface inspirée de la page d'accueil de YouTube, réalisé avec HTML et CSS.

## 🛠️ Technologies

- HTML5
- CSS3
- Google Fonts (Roboto)

## 📁 Structure

```text
youtube_html_css/
├── youtube.htm
├── channel-pictures/
├── icons/
├── thumbnails/
└── styles/
    ├── general.css
    ├── header.css
    ├── sidebar.css
    └── video.css
```

## ✨ Fonctionnalités

- Header YouTube
- Barre de recherche
- Menu latéral
- Affichage des vidéos
- Miniatures et images des chaînes
- Design responsive

## 🚀 Utilisation

Ouvrir simplement `youtube.htm` dans un navigateur.
